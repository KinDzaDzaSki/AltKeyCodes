Alt codes require a physical numeric keypad, so on a laptop with no numpad the Alt
code method is unavailable no matter which code you use. Five alternatives work
instead: a hidden Fn numpad on many laptops, the Windows Character Viewer, the
on-screen Touch Keyboard, an HTML entity in anything that renders HTML, and copying
the character directly from a reference table. Each one covers a different situation,
and the last two work on every machine that can display the character at all.

## 1. Check for an Fn numpad first

Many 13-inch and 14-inch laptops fold a numeric keypad into the letter keys. Look for
small printed numbers on the **U**, **I**, **O**, **J**, **K**, **L**, **M** area and
on the top-right keys. If you see them, you already have a numpad.

- Turn on Num Lock. On these laptops it is usually **Fn** plus **F11** or **Num Lk**,
  or a key with a padlock icon.
- Hold **Alt** and **Fn** together.
- Type the code on the emulated keypad, then release both.

If a key mark says something like `3 / PgDn`, the number is the numpad value and the
other label is what the key does without Fn.

## 2. Windows Character Viewer

The built-in Microsoft Character Viewer panel opens from **Win** + **.** (Windows
plus full stop) on Windows 10 and 11. It opens on the emoji tab by default.

1. Press **Win** + **.** to open the panel.
2. Click the **symbols** category on the top row to reach arrows, punctuation, math
   and currency.
3. Click the symbol you want. It is inserted at the cursor.

The panel remembers recently used characters, which makes a second insertion fast.
Search inside the panel is limited, so use this site's search to find the symbol name
first, then look for that name in the panel.

## 3. On-screen Touch Keyboard

The Touch Keyboard includes a full numeric keypad and accepts Alt sequences on the
keypad.

1. Right-click the taskbar and enable **Show touch keyboard button**, then click it.
   Alternatively open **Settings**, **Personalization**, **Taskbar**, and turn on
   **Touch keyboard**.
2. In the Touch Keyboard, click the options key and switch to the **numeric keypad**
   layout.
3. Hold **Alt** on your physical keyboard and click the digits on the on-screen
   keypad, then release Alt.

This is the closest thing to a real numpad and it works with every Alt code on this
site.

## 4. HTML entities and numeric escapes

Anything that renders HTML accepts an entity or a numeric escape. This covers web
pages, email signatures built in HTML, CMS article bodies, and most rich text editors
that accept pasted HTML.

- Named entity, where one exists: `&copy;` produces ©
- Decimal escape, always available: `&#169;` produces ©
- Hex escape, always available: `&#xA9;` produces ©

Decimal and hex escapes work for every code point, including ones with no named
entity. See [How to type symbols in HTML](/how-to/type-symbols-in-html/) for the
full method.

## 5. Copy the character directly

Copying is not a workaround. It is the fastest method for a character you use once.
Click any glyph tile in this site's symbol pages and the character goes to your
clipboard, ready to paste anywhere, including places that reject Alt codes entirely
such as web forms, mobile apps and chat boxes.

## FAQ

### Is there really no way to use Alt codes without a numpad?

Not on Windows. The Alt key sequence is read from the numeric keypad scan codes, so a
laptop without those keys cannot produce the sequence. The Touch Keyboard and an Fn
numpad are the two ways to present those keys to Windows.

### Do Alt codes work in Windows on a Mac keyboard?

Only if the Mac keyboard is configured to send Windows key codes and has a numpad
area. The Mac Option key is a different modifier and does not start a Windows Alt
sequence.

### What about Linux?

Linux desktops accept a similar sequence: hold **Ctrl** and **Shift**, type **u**,
then the hex code point, then press **Enter** or **Space**. For example **Ctrl** +
**Shift** + **u**, then `2713`, then **Enter** inserts ✓.
