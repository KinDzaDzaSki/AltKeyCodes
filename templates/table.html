About this table

Three-digit codes use the OEM code page 437 table. Four-digit codes with a leading zero use the Windows-1252 table. The two agree below 128 and diverge above 127. Codes 1–31 and 127 have no printable Unicode character; they draw a picture only in an OEM console font.
